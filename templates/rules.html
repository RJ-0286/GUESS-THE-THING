📖 How to Play

Master the rules, decipher clues, and build massive streaks to dominate the leaderboard!

🚀 Core Game Flow

1️⃣
Pick Setup

Select your favorite universe, challenge difficulty, and clue style.

2️⃣
Analyze Clue

Read the description or progressive hints carefully to deduce the secret thing.

3️⃣
Submit Guess

Type your answer. Aliases and common character names are recognized.

4️⃣
Chain Streaks

Correct answers in a row ignite streak bonuses for huge score multipliers!

🧩 Clue Styles Explained

Each mode offers a distinct way to experience the guessing challenge:

💡
Normal Clue

A crisp, engaging trivia description detailing key attributes, abilities, or plot points without giving away the name immediately.

"Christopher Nolan's sci-fi heist movie where thieves enter dreams within dreams..."
🧩
Progressive

Starts with a subtle hint (Tier 1). You can reveal up to 2 extra tiers if you get stuck. Each tier reveals more obvious context!

Tier 1: Subtle clue → Tier 2: Key quote → Tier 3: Direct giveaway.
🔐
Cryptic

For true puzzle masters. Poetic riddles, metaphorical wordplay, and obscure lore that require deep deductive thinking.

"A brass spindle wobbles as architectural mirrors fold cities into slumbers..."
